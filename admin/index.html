在這裡修改網站文字、作品與圖片。按「儲存並發布」後，GitHub 會自動重新產生網站，約 1–2 分鐘後上線。

儲存庫設定

怎麼取得權杖？
  1. 打開 GitHub → Fine-grained tokens → Generate new token。
  2. Repository access 選「Only select repositories」，只勾 HachimanStudio。
  3. Permissions → Repository permissions：Contents 設為 Read and write；想在後台看到上線進度，再把 Actions 設為 Read-only。
  4. 產生後複製貼到上面。權杖只會送到 api.github.com，不會經過其他伺服器。

沒勾「記住」時，關掉分頁就會忘記權杖。這台電腦不是你自己的，就不要勾。
