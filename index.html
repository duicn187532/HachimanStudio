About

嗨，我是八萬爸。

HACHIMAN STUDIO 八萬工作室是我的個人品牌，目前沒有登記營業，也不以營利為目的。工作室只有我一個人：網站上的作品有些是我獨立完成，有些是和同事、朋友合作，每件作品都寫著我負責的部分。

從銀行臨櫃起步，做過分行企業金融，現在在數位金融部規劃企業金融的數位產品(非技術職)。2023 年開始自學寫程式，2025 年進入資訊工程碩士在職專班，研究 LLM Agent 的記憶。

  • 懂金融業的限制，也能自己做出來熟悉法遵、資安與跨部門流程，主導過 3 項企業金融系統上線；能從法規與業務需求寫到 PRD 與系統分析，也能用 Python、React 親手做出原型。
  • 自學三年，16 件作品2023 年從一支爬蟲開始，現在有 3 套內部工具每天在用（合計約 150 人），也在部門裡開 JavaScript 與 Python 課。
  • 邊做產品，邊讀論文在職攻讀資工碩士，精讀 Agent 記憶相關論文並做成論文精讀室；做產品時也守同一套標準：AI 只給建議、來源要能追溯。

    How it works

    諮詢怎麼進行

    不用準備完整的文件，幾句話的描述就夠了。

    1. STEP 01

      來信說說想法

      想解決什麼、誰會用、現在怎麼做。三五句話就可以。

    2. STEP 02

      一起釐清

      我會回信問幾個問題，幫你把想法整理成比較清楚的需求與範圍。

    3. STEP 03

      給你方向

      建議可行的做法、適合的工具或技術，以及可以先試的最小版本。

    4. STEP 04

      需要的話再合作

      剛好是我做得來又有興趣的，可以一起做原型；超出範圍就找夥伴一起來。

    有想法，卻不知道該怎麼做？

    不管是一個還沒成形的點子、一個想解決的麻煩，或是好奇 AI 能不能幫上忙，都歡迎來信聊聊。這是我的業餘時間，回覆可能需要幾天，請多包涵。

    寄信諮詢 GitHub ↗
    概念諮詢要收費嗎？

    不收費。這是我的個人興趣，以分享經驗、幫你釐清方向為主，不會提供正式的報價或合約。

    可以請你直接幫我做嗎？

    看情況。小型工具或原型、又剛好在我熟悉的範疇內，可以討論一起做。想談正式的商業合作也可以，但這是個人，時間與規模有一定上限，無法像公司一樣承接大型或需要長期保固的專案。

    超出你熟悉的範圍怎麼辦？

    我會直接告訴你，盡量提供可以找的方向；也很歡迎有相關專長的人來一起合作。

    作品都是你一個人做的嗎？

    有些是我獨立完成，有些是和同事、朋友合作。每件作品的介紹裡都寫著「我的角色」，就是我負責的部分。
